[#windows]
== Установка приложения {to} на сервер под управлением Windows

.Чтобы установить {to} на сервер под управлением Windows:
. Запустите пакет установки `{dv} TakeOffice server.msi`.
+
.Мастер установки серверной части приложения {to}
image::install-server-hello.png[Мастер установки серверной части приложения {to}]
+
. Примите условия лицензионного соглашения для продолжения установки.
+
.Условия лицензионного соглашения
image::install-server-license.png[Условия лицензионного соглашения]
+
. Выберите компоненты, которые требуется установить, и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::install-server-components.png[Выбор устанавливаемых компонентов]
+
****
Серверные компоненты::
Основные серверные компоненты приложения _{to}_, обязательны для установки на сервер {dv}.

Кнопка Сброс::
Сбрасывает выбор компонентов на стандартные.

Кнопка Использование диска::
Позволяет посмотреть свободное место на системных дисках.
****
+
. Нажмите на кнопку *Установить* и дождитесь завершения установки.
+
.Мастер установки серверной части приложения {to}
image::install-server-confirm.png[Мастер установки серверной части приложения {to}]
+
. На следующем экране нажмите кнопку *Готово*, чтобы закрыть мастер установки.
+
